# 代码与模型来源

项目工作包括视觉检测部署、深度定位、安装关系转换、目标锁定、动作编排和设备联调。

`ros_robot_controller_sdk.py`、总线舵机和动作组封装，以及 `kinematics/` 中的扩展和工具来自机器人配套环境，部分封装包含项目适配。原平台为幻尔机器人；具体 SDK 版本和完整许可未随原目录保存，需向供应商核对。正逆运动学求解器并非项目从零实现。

原工程的 `ActionGroups/` 为配套动作数据，黄瓜视觉主流程不使用，本次发布不包含这些文件；动作组读取封装保留用于兼容原设备。训练和导出使用 Ultralytics YOLO11n，模型和上游依赖按各自授权使用。

本仓库不为第三方代码、二进制、动作数据及模型授予额外许可。未添加覆盖全部文件的 MIT 等许可证，以免错误声明第三方内容的授权范围。后续应补齐原始版本与许可证。
