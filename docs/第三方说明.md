# 代码与模型来源

项目工作包括视觉检测部署、深度定位、安装关系转换、目标锁定、动作编排和设备联调。

`ros_robot_controller_sdk.py`、总线舵机和动作组封装，以及 `kinematics/` 中的扩展和工具来自幻尔机器人配套环境，部分控制封装根据本项目的运动需求进行了适配。正逆运动学解算使用设备配套库。

`action_group_controller.py` 保留配套动作组的读取接口，动作数据由原设备环境提供。模型训练和导出使用 Ultralytics YOLO11n，嵌入式推理使用 ONNX Runtime。

设备 SDK、运动学扩展、模型及依赖库按各自许可使用和分发，具体授权以原提供方的条款为准。
