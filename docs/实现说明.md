# 实现说明

## 检测与定位

主节点订阅彩色图和对齐深度图，按时间差容限组合最近消息。推理线程缩放到模型输入尺寸，BGR 转 RGB、归一化并构造 NCHW 张量。后处理选择置信度最高的候选框，未实现完整多目标 NMS 或实例跟踪。

框中心映射回原图，取邻域非零深度的中位数。使用针孔模型 `X=(u-cx)Z/fx`、`Y=(v-cy)Z/fy` 反投影，坐标统一为米。代码内参对应原设备的 640×480 彩色流。

## 坐标与抓取

相机坐标按 `[Z,-X,-Y]` 映射到末端轴向，加安装偏置后，使用末端到基座的齐次变换得到目标基座坐标。末端位姿由已发送的脉冲和配套正运动学计算，未实时读取关节状态。此方法依赖安装关系，不是基于标定板与多组位姿求解的标准手眼标定。

目标位置累计到配置帧数后取中位数，默认冻结锁定坐标。没有按目标 ID 关联，也没有严格的位置方差稳定判据。

逆运动学输入包含目标位置、预设 pitch 和角度搜索范围。求解结果转换为脉冲后，优先选择与当前脉冲差较小的候选。动作包含接近、到目标、夹取、旋转、释放和复位，支持分组、逐关节和笛卡尔插值选项，不含障碍物建模及通用路径规划。

## 通信

RealSense 驱动和采摘主程序是实际 ROS2 节点，检测、坐标转换和动作决策在主节点内部完成。输入输出图像使用 `sensor_msgs/msg/Image`，控制命令通过 Python SDK 的串口协议发送到控制板。没有为这些内部模块建立自定义 service/action。
