# 实现说明

## 检测与定位

系统订阅 D435i 输出的彩色图像和对齐深度图，根据消息时间戳匹配图像。检测线程按设定间隔读取彩色图像，将图像缩放到模型输入尺寸，完成 BGR 转 RGB、像素归一化和 NCHW 维度转换，再送入 ONNX Runtime 进行推理。

程序从候选结果中选取置信度最高的黄瓜目标，将检测框映射回原始图像，在框中心邻域读取非零深度值并取中位数。结合相机内参，按照针孔模型恢复目标的三维位置：

```text
X = (u - cx) × Z / fx
Y = (v - cy) × Z / fy
Z = depth
```

其中，`u、v` 为目标像素坐标，`fx、fy、cx、cy` 为相机内参，深度与输出坐标统一使用米。当前参数对应原设备的 640×480 彩色流，更换设备后应读取对应内参。

## 坐标与抓取

根据相机与末端执行器的安装关系，程序将相机坐标按 `[Z,-X,-Y]` 映射到末端坐标轴，并叠加安装偏置。随后根据当前关节指令对应的正运动学结果，构造末端到基座的齐次变换矩阵，将目标点转换为基座坐标。

目标锁定模块收集连续多帧有效坐标，取各坐标分量的中位数确定目标位置。默认在锁定后保持该坐标，供机械臂靠近和夹取时使用，减少目标短时离开视野对动作执行的影响。

运动解算模块将目标位置、预设俯仰角和角度搜索范围传入逆运动学接口，将候选解转换为舵机脉冲，并选取与当前关节指令变化较小的方案。执行模块依次完成打开夹爪、接近目标、到达抓取点、夹取、旋转、释放和复位，支持分组运动、逐关节运动及笛卡尔插值调试。

## 通信

RealSense 相机节点负责图像采集，采摘主节点组织检测、定位和动作控制。输入输出图像通过 ROS2 话题传输，消息类型为 `sensor_msgs/msg/Image`；机械臂指令经 Python SDK 封装后，通过串口发送至 STM32F4 控制板。

| 话题 | 数据 |
| --- | --- |
| `/camera/camera/color/image_raw` | 彩色图像 |
| `/camera/camera/aligned_depth_to_color/image_raw` | 对齐深度图 |
| `/cucumber_picker/image_result` | 检测、锁定和坐标显示结果 |

网页预览通过 MJPEG 输出处理后的画面，便于在电脑或树莓派浏览器中检查运行状态。
